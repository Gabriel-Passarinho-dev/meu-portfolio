Este é um projeto da aula de Git + GitHub da disciplina de Desenvolvimento Web III no curso Tecnologia em Sistemas para Internet.
A página foi criada como teste e por parte da atividade proposta para ter um toque inicial com as ferramentas(Apesar de já ter utilizado as duas anteriormente).
A aula consiste em aprender a utilizar comandos basicos de Git para desenvolver um repositório no GitHub.

Comandos utilizados até então:
git init (Inicia o Git)
git status (Checa o status do projeto)
git add <file> (Adiciona o arquivo [Necessita mencionar o nome do arquivo no local de <file>])
git commit -m "mensagem aqui" (Salva uma "Foto" do projeto e adiciona uma pequena descrição ao arquivo)
git log (Checa as versões do projeto)
git remote add origin <link> (Conecta o repositório do GitHub com o projeto do Git)
git push -u origin main (Envia os commits para o repositório) / git pull (Também funciona assim, porém com autenticação e verificação de alterações)
git branch -M main (Cria uma branch [galho] para a versão principal do repositório)
git clone <link>(Clona o repositório para sua máquina)
